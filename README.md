## 🚀 Featured Project

### 🛒 E-Commerce Web API — Modular Monolith

**A backend application focused on modular architecture, domain modeling, and reliable business workflows.**

This project explores how to structure a substantial backend application while maintaining clear module boundaries and a single deployable unit.

**Architecture and engineering highlights**

* 🏛️ **Modular Monolith:** Organized business modules within one application.
* 🧩 **Clean Architecture:** Explicit dependency direction across API, Application, Domain, and Infrastructure layers.
* 📐 **Domain-Driven Design:** Business behavior and invariants modeled within appropriate domain boundaries.
* 🔀 **Selective CQRS:** Dedicated read models where query requirements justify them.
* 📬 **Transactional Outbox:** Reliable persistence of events alongside business changes.
* ⏱️ **Background Processing:** Hangfire integrated through an application-level scheduling abstraction.
* 🔐 **Identity and Authorization:** Authentication and authorization integrated with ASP.NET Core Identity.
* 📊 **Observability:** Structured logging, health checks, metrics, and tracing capabilities.

**Technology stack:** C# · .NET 8 · ASP.NET Core Web API · EF Core · SQL Server
